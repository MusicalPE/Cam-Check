캠핑장 찾기(카카오 장소 검색) 준비 — 처음 한 번만

키가 없어도 캠핑장 칸은 '다녀온 곳'을 찾아 줍니다.
카카오 검색까지 쓰려면 아래 순서로 JavaScript 키를 받아 저에게 보내 주세요.
(시트판과 가족판이 같은 키를 함께 씁니다)

1. https://developers.kakao.com 에 카카오 계정으로 로그인
2. [내 애플리케이션] > [애플리케이션 추가하기]
   - 앱 이름: 예) 캠핑 체크
   - 회사명: 개인이면 이름이나 음악적체육인
3. 만든 앱 > [앱 설정] > [플랫폼] > [Web 플랫폼 등록]
   - 사이트 도메인: https://musicalpe.github.io
4. [제품 설정] 또는 [앱 설정] 메뉴의 [카카오맵]에서 '사용 설정'을 켜기
   (이걸 켜지 않으면 검색이 막혀요)
5. [앱 설정] > [앱 키]에 있는 'JavaScript 키'를 복사해서 보내 주세요.
   * REST API 키, Admin 키가 아니라 JavaScript 키예요.
   * JavaScript 키는 등록한 사이트에서만 쓸 수 있어서 공개돼도 괜찮아요.
     Admin 키는 절대 보내거나 올리지 마세요.

무료로 쓸 수 있는 양이 넉넉해서 가족이 쓰는 정도로는 돈이 들지 않아요.
