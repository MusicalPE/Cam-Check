캠첵! — 파이어베이스 준비 (처음 한 번만)

캠첵! 주소: https://musicalpe.github.io/camping/


[1] 프로젝트 만들기
  1. https://console.firebase.google.com 에서 [프로젝트 추가]
  2. 이름: 예) camping-family
  3. Google 애널리틱스는 꺼도 됩니다 → [프로젝트 만들기]
  * 요금제는 무료(Spark) 그대로 두면 됩니다.

[2] 웹 앱 등록 → 설정값 받기
  1. 프로젝트 개요 화면에서 </> (웹) 아이콘
  2. 앱 닉네임: 예) camping-web  (Firebase 호스팅은 체크하지 않음)
  3. [앱 등록]을 누르면 나오는 const firebaseConfig = { ... } 부분을
     통째로 복사해서 저에게 보내 주세요. 제가 firebase-config.js 에 넣어 올릴게요.
  * 이 값은 공개돼도 괜찮은 값이에요. 누가 읽고 쓰는지는 [5] 보안 규칙이 막아요.

[3] 구글 로그인 켜기
  1. 왼쪽 메뉴 [빌드] > [Authentication] > [시작하기]
  2. [로그인 방법] 탭 > Google > 사용 설정 > 지원 이메일 고르고 [저장]
  3. [설정] 탭 > [승인된 도메인] > [도메인 추가] > musicalpe.github.io

[4] 데이터베이스 만들기
  1. 왼쪽 메뉴 [빌드] > [Firestore Database] > [데이터베이스 만들기]
  2. 위치: asia-northeast3 (서울)
  3. [프로덕션 모드에서 시작] → [만들기]

[5] 보안 규칙 넣기
  1. Firestore Database > [규칙] 탭
  2. 원래 있던 내용을 모두 지우고 보안규칙.txt 내용을 붙여 넣기 → [게시]


쓰는 방법
  1. 캠첵! 주소를 열고 [구글로 로그인]
  2. 처음이면 [가족 공간 만들기] — 이 기기에 있던 목록(시트판에서 쓰던 목록 포함)이 그대로 올라갑니다
  3. 위쪽 [가족 초대 QR]을 아내에게 보여 주거나 [링크 복사]로 보내기
  4. 아내가 찍고 구글로 로그인하면 같은 가족 공간에 들어옵니다

시트판과 달라지는 점
  - 껍데기, 배포, /exec 주소, 비밀 코드가 없습니다.
  - 아내가 체크하면 내 화면에 거의 바로 보입니다(20초 기다림 없음).
  - 인터넷이 끊긴 캠핑장에서 체크해도, 신호가 잡히면 알아서 올라갑니다.
  - 캠핑 기록은 구글 시트 대신 파이어베이스에 쌓입니다.
    (시트판에 쌓인 기록 옮기기와 엑셀로 내려받기는 필요하면 다음에 붙일게요)

아이폰 홈 화면 앱에 대해
  아이폰은 홈 화면에 추가한 앱 안에서 구글 로그인 창이 잘 안 열릴 때가 있어요.
  그럴 땐 사파리에서 가족판을 열어 쓰시거나, 안 되는 화면을 알려 주세요.
