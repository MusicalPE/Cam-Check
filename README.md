# 캠첵! Cam-Check

가족이 함께 쓰는 캠핑 준비물 체크리스트와 캠핑 기록입니다.

- 주소: https://musicalpe.github.io/Cam-Check/
- 구글로 로그인해 가족 공간을 만들고, 가족 초대 QR로 함께 씁니다.
- 체크는 실시간으로 함께 보이고, 인터넷이 끊겨도 기기에 두었다가 연결되면 올라갑니다.

## 할 수 있는 것

- 구역별 준비물 체크, 꼭 챙길 물건 강조, 구역 접기, 챙긴 것 숨기기
- 출발 체크 / 철수 체크(챙겨 간 것만 다시 체크, 먹거리는 빼고)
- 연필로 고치기, 끌어서 순서 바꾸기, 빼고 나서 되돌리기
- 상황 설정: 차박·추울 때·더울 때처럼 상황을 만들고 버튼으로 켜고 끄기
- 식단: 날짜별 끼니에 메뉴와 재료를 적으면 재료가 먹거리 구역에 저절로
- 캠핑장 찾기(카카오 검색·주소), 날씨 예보 표(하늘·비·바람·기온, 주의 표시)
- 캠핑 기록과 우리 별점, 다른 가족들과 캠핑장 별점 나누기
- 준비물 세팅 공유(짧은 주소·QR), 자매 앱 트립첵!으로 가기, 업데이트 소식
- 계정·자료 관리: 기록 내려받기(CSV), 가족 공간에서 나가기, 계정과 자료 모두 지우기

## 준비

- 파이어베이스: `파이어베이스_준비.txt`, 보안 규칙 `보안규칙.txt`
- 카카오 장소 검색 키: `kakao-config.js`
