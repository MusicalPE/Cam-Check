# 캠첵! Cam-Check

가족이 함께 쓰는 캠핑 준비물 체크리스트와 캠핑 기록입니다.

- 주소: https://musicalpe.github.io/Cam-Check/
- 구글로 로그인해 가족 공간을 만들고, 가족 초대 QR로 함께 씁니다.
- 체크는 실시간으로 함께 보이고, 인터넷이 끊겨도 기기에 두었다가 연결되면 올라갑니다.

## 할 수 있는 것

- 구역별 준비물 체크, 챙긴 것 숨기기, 체크 모두 지우기
- 연필로 항목·구역 이름 고치기, 휴지통으로 빼기, 손잡이를 끌어서 순서 바꾸기(다른 구역으로도)
- 상황 설정: 차박·추울 때·더울 때처럼 상황을 직접 만들고, 항목·구역에 붙여 버튼으로 켜고 끄기
- 캠핑 기록: 출발일·박·캠핑장·최저기온·메모·우리 별점, 챙긴/안 챙긴 항목, 기록 고치기
- 캠핑장 찾기: 다녀온 곳과 카카오 장소 검색, 카카오맵·네이버 지도 바로 가기, 우리 캠핑장 순위
- 다른 캠퍼들과 별점 나누기: 캠핑장마다 가족 한 표씩 평균 별점(가족 정보는 올라가지 않음)
- 앱으로 설치(홈 화면 아이콘)

## 준비

- 파이어베이스: `파이어베이스_준비.txt`, 보안 규칙 `보안규칙.txt`
- 카카오 장소 검색 키: `카카오_장소검색_준비.txt` (키는 `kakao-config.js`)
