# 캠핑 준비물 체크리스트

오토캠핑·차박 준비물을 구역별로 체크하고, 다녀온 캠핑을 날짜별로 구글 시트에 쌓아 두는 화면입니다.
가족이 같은 시트에 연결하면 휴대폰마다 같은 목록과 체크를 함께 볼 수 있어요.

- 화면: https://musicalpe.github.io/camping/
- 시트 껍데기: `shell/Code.gs`

## 할 수 있는 것

- 구역별 체크리스트(사이트 구축, 차박 세팅, 침실, 전기·난방, 거실, 주방, 화로, 먹거리, 개인, 놀거리)
- 연필 아이콘으로 항목·구역 이름 바로 고치기, 손잡이를 끌어서 항목·구역 순서 바꾸기(다른 구역으로도), 항목 넣기·빼기, 구역 추가·삭제
- 상황 설정: 차박·추울 때·더울 때처럼 상황을 직접 만들고 이름을 바꾸고, 항목·구역에 붙여 버튼으로 켜고 끄기
- 캠핑 기록: 출발일·박·캠핑장·최저기온·메모·우리 별점과 챙긴/안 챙긴 항목을 시트에 한 줄씩 저장
- 캠핑장 찾기: 다녀온 곳과 카카오 장소 검색(키는 `kakao-config.js`), 카카오맵·네이버 지도 바로 가기, 우리 캠핑장 순위
- 가족판에서는 우리 별점을 다른 캠퍼들과 나눠 캠핑장마다 평균 별점을 보여 줌(가족 정보는 올라가지 않음)
- 두 사람이 동시에 체크해도 서로 지우지 않게 체크는 한 칸씩 저장

## 설치

1. 구글 시트를 새로 만들고 [확장 프로그램] > [Apps Script]를 엽니다.
2. `shell/Code.gs` 내용을 붙여 넣고, 맨 위 `SECRET` 값을 원하는 비밀 코드로 바꿉니다.
3. [배포] > [새 배포] > 웹 앱
   - 다음 사용자 인증 정보로 실행: 나
   - 액세스 권한이 있는 사용자: 모든 사용자
4. 웹 앱 주소(/exec)를 열면 화면으로 넘어가면서 자동으로 연결됩니다.
5. 함께 쓸 사람에게도 같은 /exec 주소를 보내 한 번 열게 하면 됩니다. 그 뒤로는 화면 주소만 열면 돼요.

시트에 연결하지 않으면 그 기기의 브라우저에만 저장됩니다.
